# Vehicle Re-ID — веб-демо

Простая статическая страница (`index.html`, без сборки/фреймворков). Живёт
на ноуте, а инференс (детектор + дообученный эмбеддер + поиск) — на A100.
Сайт и API — разные origin, поэтому сначала нужно пробросить порт API.

## 1. Пробросить API-порт с A100 на ноут

API на сервере слушает `0.0.0.0:8800` (уже запущен в фоне). Прокинуть его
на свой `localhost:8800` через тот же jump-proxy, что и SSH:

```bash
ssh -p 40007 -fN -L 8800:172.16.2.93:8800 ansible-server@89.125.151.113
```

Проверить: `curl http://localhost:8800/health` должен вернуть `{"status":"ok",...}`.

## 2. Открыть сайт

Любой локальный статический сервер подойдёт (просто открыть `index.html`
как `file://` тоже работает в большинстве браузеров, но со статик-сервером
надёжнее):

```bash
cd web && python3 -m http.server 5500
# затем открыть http://localhost:5500
```

По умолчанию страница ходит на `http://localhost:8800`. Если API
проброшен на другой порт/хост — добавить `?api=http://host:port` к
адресу страницы.

## Что показывает страница

Перетаскиваешь фото машины → `/identify` возвращает цифровой профиль
(цвет/кузов/особенности — zero-shot CLIP; марка/модель — дообученные
головы, если бэкенд их подключит) и список похожих машин из базы
(`/data/index/...` — кропы, которые уже добавлены через `/enroll`).
